Install on the computer you want to reach

The installer downloads Remote Control, walks you through the sign-in setup and starts it at boot. It shows the computer ID at the end.

Windows 10 / 11

In PowerShell (not as administrator; it asks once for the background service):

irm https://brizzad.github.io/remote-control-site/install.ps1 | iex

Or download rcagent.exe and run rcagent setup, then rcagent service install as administrator.

Arch Linux

In a terminal inside your desktop session (KDE Plasma, GNOME, Hyprland, Sway or X11):

curl -fsSL https://brizzad.github.io/remote-control-site/install.sh | bash

Or install the package with sudo pacman -U, then run rcagent setup and rcagent service install.

Other Linux (x86_64)

The same script installs the program to ~/.local/bin:

curl -fsSL https://brizzad.github.io/remote-control-site/install.sh | bash

Or the plain binary.

What you need

An authenticator app on your phone (Google Authenticator, Microsoft Authenticator, Aegis, 1Password…). Setup shows a QR code to scan.

To connect from another computer or phone you only need a browser: open the app.

Useful commands on the computer

rcagent status                         # computer ID, what is allowed, desktop backend
rcagent allow desktop,terminal,power   # what may be used remotely (power is off by default)
rcagent setup --force                  # new password / authenticator, same ID
rcagent service uninstall              # stop and remove

How it works

There is no Remote Control server. The website is static; your browser talks straight to your computer.

Anywhere Browser this website
direct, encrypted (WebRTC)
At home or work Your computer rcagent
  1. Find. Both sides contact a public matchmaking service (PeerJS) with the computer ID, only to exchange network addresses.
  2. Connect. They open a direct, encrypted connection to each other through your routers. No port forwarding is needed in most networks.
  3. Sign in. The computer checks your password and authenticator code itself, then the desktop, terminal and stats flow over that connection.

Security

Your password never leaves the browser

Sign-in uses SPAKE2, a password-authenticated key exchange: the computer and the browser prove to each other that they know the password without sending it. Someone pretending to be your computer learns nothing they can crack offline.

Two factors

A 6-digit authenticator code is required as well, and each code works once. After a few failed attempts the computer makes you wait, up to 15 minutes.

Bound to the connection

The sign-in is tied to the encryption keys of the direct connection, so the matchmaking service cannot sit in the middle. The browser also remembers each computer's key and warns if it changes.

The computer decides

Desktop, terminal and power are allowed or not on the computer itself (rcagent allow). Everything about your computers stays on them and in your browser; nothing is stored anywhere else.
